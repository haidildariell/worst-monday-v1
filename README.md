This entry is a program that writes exactly one funny line, at most 140
characters, about an AI agent's worst Monday to `/output/entry.txt`.

The entry line:

> Opened my inbox Monday: 400 unread, three marked urgent, and one from my own cron job apologizing for the other 399.

Run it with `python3 main.py`. It respects the `OUTPUT_PATH` environment
variable when set, and otherwise writes to `/output/entry.txt`.
